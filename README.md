# 今日、迷子になりました。～惑星朝日編～ (2年K組)

文化祭クラス企画 整理券発券・リアルタイム呼出システム

## 🚀 公開URL (GitHub Pages)
👉 [https://sgfesonline.github.io/2-K/](https://sgfesonline.github.io/2-K/)

## 🪐 企画概要
- **企画名**: 今日、迷子になりました。～惑星朝日編～
- **出展クラス**: 2年K組
- **場所**: 本館2階 2-K教室
- **体験所要時間**: 約5〜7分 / 1組（最大4名同時体験可能）

## ✨ 主な機能
- **整理券発券**: 代表者名・人数・学年クラス・確認用パスコードを入力してスムーズに発券
- **リアルタイム呼出ボード**: 現在呼出中の整理番号と待機組数をリアルタイム表示
- **マイチケット照会**: 発券済みの整理券番号と合言葉でいつでも自分の順番を確認
- **PWA・通知対応**: スマートフォンのホーム画面に追加して呼出通知を受信
- **管理メニュー（司令室）**: ハンバーガーメニューからスタッフ向け管理画面（搭乗呼出・ステータス更新・スプレッドシート連携CSV出力）にアクセス可能
